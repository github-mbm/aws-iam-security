# Secure AWS DevOps Pipeline

## Overview
This project demonstrates a secure AWS infrastructure deployment using Terraform and Jenkins.

## Services Used
- IAM
- Secrets Manager
- SSM Parameter Store
- KMS
- CloudTrail
- GuardDuty
- WAF
- EC2

## Features
- No hardcoded secrets
- Encrypted storage
- CI/CD pipeline
- Threat detection enabled

## How to Run
1. terraform init
2. terraform apply
3. Access EC2 IP:5000
